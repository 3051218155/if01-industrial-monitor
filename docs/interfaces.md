# 接口说明

## AXI-Lite

| 地址 | 名称 | 说明 |
|---|---|---|
| `0x00` | `VERSION` | 版本和复位状态 |
| `0x04` | `STATUS` | PL 就绪与传感器状态 |
| `0x40` | `MOTOR1_CTRL` | 1 号电机方向和使能 |
| `0x44` | `MOTOR1_PWM` | 1 号电机 PWM，范围 0 到 1000 |
| `0x48` | `MOTOR2_CTRL` | 2 号电机方向和使能 |
| `0x4C` | `MOTOR2_PWM` | 2 号电机 PWM，范围 0 到 1000 |
| `0x50` | `RS485_TX_DATA` | RS485 发送数据 |
| `0x54` | `RS485_RX_DATA` | RS485 接收数据 |
| `0x58` | `RS485_STATUS` | RS485 状态 |
| `0x5C` | `RS485_CTRL` | RS485 使能、清标志和 DE |

完整位域见 `firmware/pl/rtl/fpga_if01_reg_map.v`。

## Modbus

板端从站默认使用 `9600 8N1`。PC 端按设备编号轮询，主要寄存器如下：

| 寄存器 | 内容 |
|---:|---|
| 0 | 电机控制 |
| 1 | PWM |
| 2-4 | 三轴加速度 |
| 5 | 温度 |
| 6-8 | 三轴角速度 |
| 9 | 状态与数据标志 |
| 10-11 | 低、高告警阈值 |
| 12-13 | 振动 RMS、峰值 |
| 14 | 器件编号 |
| 15 | 电流 |
| 16-20 | 五点振动特征 |
| 21 | 故障部位 |

## TCP

网关默认监听 `0.0.0.0:9000`。请求和响应均为一行 JSON。常用命令：

```json
{"cmd":"list_devices"}
{"cmd":"query_device","device_id":1}
{"cmd":"query_waveform","device_id":1,"n":128}
```

## HTTP

PC 端默认监听 `8760`，供香橙派和局域网工具调用。接口只开放查询、设备切换、刷新分析、报告和 1 号电机控制。
